## 今天首先跑通了一个getpid的Demo

```c
#include "kernel/types.h"
#include "user/user.h"

int main(void)
{
  int pid = getpid();
  printf("my pid = %d\n", pid);
  exit(0);
}
```

## 今天只弄清楚一件事：程序里的 PID 是怎么从内核拿到的。

### 1. 首先我们在内核的 sysproc.c 文件中读取这个函数

```c
uint64 sys_getpid(void)
{
  return myproc()->pid;
}
```

---

```c
// 每个进程的状态信息
struct proc {
  struct spinlock lock;

  // 访问以下字段时，必须持有 p->lock：
  enum procstate state;        // 进程状态
  void *chan;                  // 非空时，表示进程正在该等待通道上睡眠
  int killed;                  // 非零时，表示进程已被标记为需要终止
  int xstate;                  // 退出状态，供父进程通过 wait 获取
  int pid;                     // 进程编号（PID）

  // 访问以下字段时，必须持有 wait_lock：
  struct proc *parent;         // 父进程

  // 以下字段由进程自己使用，访问时不需要持有 p->lock。
  uint64 kstack;               // 内核栈的虚拟地址
  uint64 sz;                   // 进程内存大小，单位为字节
  pagetable_t pagetable;       // 用户页表
  struct trapframe *trapframe; // 供 trampoline.S 使用的数据页
  struct context context;      // 进程上下文，供 swtch() 切换并恢复进程执行
  struct file *ofile[NOFILE];  // 已打开文件的指针数组
  struct inode *cwd;           // 当前工作目录
  char name[16];               // 进程名称，用于调试
};
```

先把 `struct proc` 理解为“内核保存的进程档案”。其中记录进程编号、状态、页表等信息。今天先理解 `pid` 这一项。

### 2. 我们对 sysproc.c 的代码进行了一些修改

```c
uint64 sys_getpid(void)
{
    int pid = myproc()->pid;
    printf("[kernel] getpid returns %d\n", pid);
    return pid;
}

// 我们对我们的pidtest程序也进行了修改：
int main(void)
{
    int first = getpid();
    int second = getpid();
    printf("first=%d, second=%d\n", first, second);
    exit(0);
}
```

最后的输出：

```text
[kernel] getpid returns 3
[kernel] getpid returns 3
first=3, second=3
```

### 1. 理解这次实验说明了什么

- 同一个程序连续调用两次 `getpid()`，得到相同 PID：它查询现有编号。
- 重新运行一次 `pidtest`，通常得到新的 PID：Shell 创建了新的进程来运行程序。
- 用户程序和内核通过系统调用交换数据：程序发起请求，内核返回结果。

## 那我们现在的整个程序的执行过程是：

```text
getpid → ecall → usertrap → syscall → sys_getpid
```

| 名称 | 它是什么 | 负责什么 |
| --- | --- | --- |
| `getpid()` | 用户态的函数入口 | 向内核请求“查询当前进程的 PID” |
| `ecall` | RISC-V 的 CPU 指令 | 触发陷入，使 CPU 进入内核处理流程 |
| `usertrap()` | 内核中的陷阱处理函数 | 判断进入内核的原因；如果是系统调用，就调用 `syscall()` |
| `syscall()` | 内核中的系统调用分发函数 | 读取系统调用编号，找到对应的处理函数 |
| `sys_getpid()` | 内核中查询 PID 的具体实现 | 读取当前进程的 PID 并返回 |
