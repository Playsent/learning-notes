## 如何使用

1. 打开每日记录模板，复制其中的 Markdown 内容。
2. 回到仓库首页，选择 **Add file → Create new file**，文件名填 `daily/YYYY-MM-DD.md`（替换成实际日期）。
3. 粘贴模板，用自己的话写下理解、练习和问题；不必每天都写。
4. 点击 **Commit changes**，说明本次学了什么，例如“学习记录：循环练习”。
5. 每周参考回顾模板，在 `weekly/` 中保存一篇回顾。

后续可按学习主题添加目录，练习代码和小项目可以放到 `projects/`。

## 记录原则

- 用自己的话解释，注明参考资料。
- 不确定的地方标记“待验证”。
- 不上传密码、API 密钥、个人隐私或无权公开的资料。
